# FeldtStudies Research Group

Official website for the FeldtStudies research group at Chalmers University of Technology.

## About

This website is built using Jekyll with the Agency theme, customized for academic research group presentation.

## Website Structure

### Team
Team members and info are in `_config.yml`
Images are in `/img/team/`

### Portfolio/Projects
Research projects are in `/_posts`
Images are in `/img/portfolio`

### About
Images are in `/img/about/`

## Local Development

This site uses Jekyll. To run locally:

```bash
bundle install
bundle exec jekyll serve
```
